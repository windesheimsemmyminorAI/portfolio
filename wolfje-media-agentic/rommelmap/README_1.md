## Samenvatting analyse

2. Staart hing laag aan de zijkant → moet omhoog/over de rug krullen.
3. Beenbevedering ("broek") verdwenen → expliciet teruggebracht.
4. Vacht te plat/vector → langharig en gevederd houden.
