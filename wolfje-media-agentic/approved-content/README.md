# Approved Content

Hier worden de goedgekeurde strips en video's per seizoen opgeslagen — tevens als bewijsmateriaal voor het portfolio.

```
approved-content/
├── season-1/   (dag 1–7)
└── season-2/   (dag 8–15)
```

Suggestie voor bestandsnaamgeving: `day-01_garden-first-time/` met daarin de strip (PNG's), de short (MP4) en een `metadata.json` (titels, posttijden, tags).
